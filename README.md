# CS499-Software-Engineering-Enhancement
Original IT-145 Grazioso Salvare Rescue Animal System and CS-499 software engineering enhancement.

Project Overview:

This repository contains the original and enhanced versions of my Grazioso Salvare Rescue Animal System, a Java application developed in IT-145 at Southern New Hampshire University. I revisited this project for my CS 499 capstone to demonstrate how my software engineering skills have improved.

Repository Contents:

Original-IT145: The original application, demonstrating my early understanding of object-oriented programming and inheritance.

Enhanced-CS499: The improved application, featuring a more organized design, better input validation, and automated testing.

Key Enhancements:

- Separated animal management and reservations into dedicated service classes.

- Organized the code into application, model, service, and testing packages.

- Improved input validation, error handling, and menu navigation.

- Added reservation eligibility checks and duplicate record prevention.

- Implemented 27 JUnit 5 tests to verify functionality.

- Technologies Used:

  Java | Eclipse IDE | JUnit 5

Running the Application:

Import the enhanced project into Eclipse and run Driver.java from the grazioso.app package. To run the automated tests, execute AnimalSystemTest.java as a JUnit test.
